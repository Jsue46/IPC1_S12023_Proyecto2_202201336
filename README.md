# Digital Image Processing and Pixel Manipulation Engine in Java

Academic project developed for the **Introduction to Programming and Computing 1** course at the Universidad de San Carlos de Guatemala (First Semester 2023).

This repository contains a desktop digital image processing application built in Java, providing algorithmic pixel manipulation and image transformations across multiple formats (BMP, JPG, PNG).

---

## Overview

The application reads bitmap and compressed image formats, accesses individual pixel RGB color channels, and executes programmatic transformations including grayscale filtering, horizontal and vertical mirroring, rotation, and file format conversions without relying on high-level photo editing libraries.

---

## Key Features

- Raw pixel manipulation through RGB color models
- Multiple spatial transformation algorithms (horizontal/vertical flip, 90/180/270 degree rotation)
- Grayscale and color threshold filtering
- Format conversion between BMP, PNG, and JPEG
- Graphical or command-based user interface for batch processing

---

## Technologies

- **Language:** Java (JDK 17+)
- **Image Processing:** Custom matrix operations, Java AWT / BufferedImage
